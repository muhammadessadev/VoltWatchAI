# VoltWatch

This application was built using the following tech stack:

*   **Frontend Library:** React 18.2.0 (using Functional Components and Hooks)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS (loaded via CDN for rapid prototyping without build steps)
*   **Module System:** Native ES Modules (ESM) using `<script type="importmap">` (No bundler like Webpack or Vite required, runs directly in the browser)
*   **Icons:** Lucide React
*   **AI Integration:** Google Gemini API (`@google/genai` SDK) for smart planning, chat, and weekly reports.
